# 天空之鲸 · 旅途（Sky Whale Journey）

一段在浏览器中运行的三维奇幻旅程：披橙色斗篷的小旅人从崖边草坡出发，穿过森林与河谷、跨过石桥，奔向远方的神话城堡；一头巨大的座头鲸在城堡与雪山之间的天空里缓慢巡游。
放着不管，它会自动演完整段旅程并循环；按下方向键就可以亲自操控旅人自由探索。

**在线体验：https://daipihsy.github.io/sky-whale-journey/**（需要支持 WebGL2 的桌面浏览器）

纯 three.js（r170）实现，模型、贴图、动画和声音全部由代码程序化生成，没有外部美术或音频素材。

## 启动

```bash
cd sky_whale_journey
python3 serve.py          # 浏览器打开终端里显示的地址（默认 http://localhost:5178）
```

- 端口被占用时，`serve.py` 会自动改用下一个空闲端口。
- 首次运行如果缺少 `node_modules`，先执行 `npm install`。
- 需要支持 WebGL2 的桌面浏览器（Chrome / Edge / Safari 17+）。
- 浏览器要求用户先有一次交互才能出声：点一下画面或按任意键就会开启声音。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动（相对镜头方向）；一按就从自动旅程切换到自由探索 |
| Shift | 慢走 |
| 空格 | 跳跃；在空中按住空格可以展开斗篷滑翔 |
| F | 呼唤：发出光环和钟鸣般的声音；在钟拱附近会敲响古钟。巨鲸会用鲸歌回应，然后离开巡游路线、俯冲而来从你头顶低空掠过，再爬升回到原来的路线（约 40–50 秒后到达；自动旅程里旅人也会在途中呼唤一次） |
| 鼠标拖动 / 滚轮 | 旋转视角 / 拉远拉近 |
| P | 在自动旅程和自由探索之间切换（45 秒无操作也会自动回到旅程） |
| M | 静音 |
| Q | 切换画质：高 / 中 / 低（慢的电脑也会自动降低分辨率） |
| T | 时间流动 / 暂停 |
| Y | 切换天气：晴 → 多云 → 雨 → 雾 → 自动 |
| [ / ] | 时间倒退 / 前进 1 小时 |
| H | 隐藏或显示操作说明和时间面板 |

右上角的**时间面板**可以选择天气（自动 / 晴 / 多云 / 雨 / 雾：阴天会让天空转灰、阳光变柔，积云变厚，雾更浓，下雨时有雨丝、雨声和远处的雷声，雨过天晴且阳光斜照时会出现彩虹），也可以拖动滑块调到一天中的任意时刻，切换播放/暂停与流速（默认 1 分钟 = 1 小时），或一键跳到日出、正午、黄昏、夜晚。
入夜后：满天星辰和银河、偶尔划过的流星、月亮从城堡上空划过、城堡窗户亮起暖光、萤火虫在草地上闪烁、湖面泛起蓝色荧光、蟋蟀代替鸟鸣；巨鲸通体发出生物荧光（参考《少年派的奇幻漂流》夜海里的鲸鱼）——侧线光点、喉部褶纹和头部瘤节发光，光波从头流向尾，身边散落发光的浮游生物。

走进城门的光里，会从草坡重新开始旅程。走进深水时，画面会柔和地转白，把旅人送回岸边。

## 画面构成

| 模块 | 文件 | 说明 |
| --- | --- | --- |
| 世界布局 | `src/world.js` | 高度场：崖边草坡、湖泊与石柱小岛、河谷、山脊、城堡台地、雪山；旅程路径；地形材质（草地/岩石/泥路/雪的细节纹理与凹凸） |
| 大气与昼夜 | `src/atmosphere.js` | 昼夜系统（太阳/月亮轨迹、按太阳高度插值的天空色板、光照与曝光）、全局共享的天空 uniform、星空银河与月亮、随高度衰减的空气透视雾；天空实时生成环境光照（IBL） |
| 夜晚 | `src/night.js` | 萤火虫 |
| 天气 | `src/weather.js` | 晴/多云/雨/雾的平滑过渡与自动变化、彩虹、雨丝 |
| 体积云 | `src/clouds3d.js` | 850–1750 米的积云层：三维噪声光线步进、自阴影、前向散射、被山体遮挡、空气透视 |
| 城堡 | `src/castle.js` | 城墙门楼、两层台地、大殿与双塔、主塔（方基座→八角钟楼→尖顶）、塔楼、拱廊、多拱石桥；窗户生成时会剔除被遮挡或穿模的 |
| 座头鲸 | `src/whale.js` | 按《The Sky Whale》设定图建模：石板蓝背部渐变到柔和的灰蓝体侧与细碎浅色斑点、白色腹部与喉部褶纹、吻部和下颌成排的瘤节、带波状前缘的长胸鳍、锯齿尾鳍、金色逆光轮廓；沿平滑曲率设计的环线巡游，脊椎跟随路径弯曲、转弯前预先侧倾、胸鳍转舵；听到呼唤会来访并从头顶掠过；夜晚生物荧光 |
| 旅人 | `src/character.js` | 波波头发、脸部、连衣裙、皮靴、腰带；平滑四肢；步态系统（待机/走/跑/跳/滑翔/呼唤，脚步落地锁定）；布料斗篷和围巾 |
| 操控 | `src/controller.js` `src/input.js` | 地形/桥面行走、台阶、陡坡与深水限制、城堡墙体（BVH 射线）与树石碰撞、跳跃滑翔 |
| 声音 | `src/audio.js` | 风、水流与瀑布、分地面材质的脚步、呼唤、鲸歌、钟声、生成式背景音乐 |
| 其他 | `src/vegetation.js` `src/clouds.js` `src/water.js` `src/extras.js` `src/birds.js` | 贴片叶簇的云杉与阔叶树（分块剔除、远处切换成低模）、会被脚步拨开的草、风化岩石、低空云海、带实时倒影的湖面与瀑布、浮空岛、塔尖光柱与光环、湖上塔楼、钟拱飘带、飞鸟 |
| 导演 | `src/main.js` | 自动旅程的镜头构图、自由探索的跟随镜头与碰撞、城门入光过渡；级联阴影（3 层，远处降频）；后期（AO、体积云、泛光、光束、调色、FXAA）；画质档位与自适应分辨率 |

## 调试参数（可选）

| 参数 | 作用 |
| --- | --- |
| `?s=500` | 从旅程第 500 米开始 |
| `?wt=150` | 鲸鱼时间偏移（秒） |
| `?nov` | 跳过开场光幕 |
| `?stats` | 右上角显示帧率 |
| `?noao` | 关闭环境光遮蔽（同时关闭体积云） |
| `?noclouds` | 关闭体积云 |
| `?norefl` | 关闭湖面倒影 |
| `?lowshadow` | 低分辨率阴影 |
| `?q=medium` / `?q=low` | 以中 / 低画质启动 |
| `?h=22` | 从 22:00 开始 |
| `?weather=rain` | 固定天气（clear / cloudy / rain / fog），不带则为自动 |
| `?tpause` | 时间暂停 |
| `?tspeed=360` | 时间流速（游戏秒 / 现实秒，60 = 1 分钟一小时） |
| `?pr=1` | 固定像素比（关闭自适应分辨率） |
| `?cam=whale&rel&ox=0&oy=-80&oz=600` | 以鲸鱼坐标系观察鲸鱼 |
| `?cam=trav&a=-2&d=3` | 近距离观察旅人 |

控制台中 `__advance(秒)` 可以不渲染地快进模拟，并返回连续性统计；`__keys(['KeyW'], 秒)` 可以模拟按键；`__time(小时)` 直接跳到某个时刻。
